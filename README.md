# consistentgains

A simple workout tracker designed to make logging gym sessions quick and low-friction.

## Version History

### V1: Core Workout Tracking

* **Workout selection:** Choose Push, Pull, Legs, or Custom to start a workout. The timer starts immediately.
* **Exercise logging:** Log sets with weight and reps. Fields are pre-filled from your previous session for each exercise, minimising typing.
* **Automatic volume tracking:** Volume is calculated per set, per exercise, and for the overall session.
* **Add exercises mid-workout:** Add exercises from a dropdown or enter a new exercise.
* **Workout timer:** Finish a workout to stop the timer and record the session.
* **Workout history:** View previous sessions, with expandable set details and a progress chart showing top-set weight over time for a selected exercise.

### V2: Workout Convenience

* **Expanded templates:** Templates include more exercises for each workout day.
* **Rest timer:** A rest timer starts after logging a set.
* **Unit toggle:** Switch between kilograms and pounds.
* **Data portability:** Import and export workout data as CSV.
* **Session editing:** Edit previously recorded workouts.

### V3: Progress Tracking

* **Workout cancellation:** Cancel a workout if it was started accidentally.
* **Graphs dashboard:** Dedicated graphs tab with:

  * Workout streaks
  * Monthly calendar with colour-coded workout days
  * Exercise progress
* **Body weight tracking:** Record body weight and view changes over time.
